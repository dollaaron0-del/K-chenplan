REWE-Bookmarklet einrichten

Das Bookmarklet ist ein Lesezeichen in deinem Browser. Wenn du es auf einer REWE-Bestellseite anklickst, liest es automatisch alle Artikel und Mengen aus und kopiert sie in die Zwischenablage — du musst nur noch in den Tab „REWE-Import" wechseln und Strg+V drücken.

Schritt 1: Lesezeichen-Leiste einblenden

Falls die Leiste oben im Browser nicht sichtbar ist:
Edge/Chrome: Strg+Shift+B drücken

Schritt 2: Bookmarklet hinzufügen

Den folgenden Link auf die Lesezeichen-Leiste ziehen (Maustaste gedrückt halten und raufziehen):

📋 REWE → Vorrat

← diesen Link auf die Lesezeichen-Leiste ziehen

Klappt das Ziehen nicht? Rechtsklick auf den Link → „Als Lesezeichen speichern" → in die Lesezeichen-Leiste speichern.

Schritt 3: Benutzen

  1. Auf rewe.de einloggen → Mein Konto → Meine Bestellungen → eine Bestellung öffnen
  2. Auf 📋 REWE → Vorrat in der Lesezeichen-Leiste klicken
  3. Es erscheint kurz eine Meldung „X Artikel kopiert" — dann zu dieser Datei wechseln
  4. Tab REWE-Import öffnen → Strg+V → Analysieren
⚠ Bookmarklet noch nicht getestet? Das Bookmarklet kennt die genaue REWE-Seitenstruktur noch nicht. Wenn nach dem Klicken die Meldung „Keine Artikel gefunden" erscheint, drücke F12 auf der REWE-Seite, klicke auf einen Artikel in der Liste und schick einen Screenshot davon — dann passe ich es exakt an.

Was passiert, wenn Python installiert ist?

Sobald Python auf dem PC verfügbar ist (z. B. aus dem Microsoft Store), gibt es einen noch schnelleren Weg: Ein lokaler Mini-Server macht den Import vollautomatisch — ein Klick auf das Lesezeichen, und der Einkauf ist bereits verbucht, ohne dass du etwas kopieren musst. Das können wir jederzeit nachrüsten.

Über „Speicherdatei wählen" wird jede Änderung automatisch in eine vorratsdaten.json geschrieben (kompatibel mit der Python-Version). Zusätzlich werden die Daten im Browser gespeichert. Geht der Browser-Speicher verloren, lädst du die Speicherdatei einfach über „Daten laden (Import)" wieder ein.
